## 使用约定

- 一轮只做一个任务。
- 先讲原项目做法，一次给出当前任务的完整流程、伪代码、关键片段和验收方法，由用户按步骤编写；不强制先答题，不在步骤之间等待“继续”。直接实现或完整代码按用户明确授权执行。
- 不提前创建本任务不需要的包和表。
- 装依赖前先说明名称、用途和版本，等我确认。
- 验收没跑过就保持未完成，并注明「未运行」。

## T05 实现步骤（一次完整指导，按步骤编写）

当前源码中尚无 T05 连接模块，以下均未验收；不使用已删除的待应用包。

1. **协议与入口**：读原项目 WebSocket 入口和 proto；解释 BinaryMessage、ImWebsocketMsg、命令号。指导接入 GET /im，先验握手；握手不算登录成功。
2. **Connect 与鉴权**：读原项目连接处理器，复用已有应用查询和 token.Parse；指导解析 Connect，返回成功或失败 ConnectAck。验合法、非法及跨应用 Token。
3. **本地 session**：鉴权成功后登记身份；断网和主动 Disconnect 清理。解释 map 的并发保护，不实现多设备互踢。
4. **Ping/Pong 与超时**：解释 IM 心跳和 WebSocket 控制帧区别；指导续期与超时清理，明确学习实现和原项目的差异。
5. **payload 混淆**：核对原项目 XOR 规则，兼容 payload 与 oneof，保留真实命令号，不自行定义帧头。
6. **启动与退出验收**：接入配置和进程入口，检查退出时关闭已升级连接；运行适当测试和真实 MySQL + 9003 验收后，才标记 T05 完成。

步骤只细化 T05，不新增任务编号。一次覆盖本任务尚未完成部分：原项目位置与解释、文件分工、步骤间衔接、关键片段和完整验收方法，由用户按顺序编写后集中检查。其他任务采用同样方式；只有用户要求慢讲或出现真实阻塞时才中途暂停，不提前实现后续任务。
